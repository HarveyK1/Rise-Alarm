# Features (v0.7.0)

✅ = confirmed working on the iPhone  ·  🧪 = built, not confirmed yet  ·  ❌ = removed

## Alarms
- ✅ Time, repeat days (or once), label, on/off toggle, swipe to delete. Next ring shown as "Rings in …".
- ✅ 5 built-in sounds **generated by the app** (Beeps, Siren, Buzzer, Chirps, Chimes); no copied audio.
- ✅ Volume per alarm (sets the phone volume when it rings). Preview plays at that volume, then restores yours.
- ✅ Snooze interval (Off / 1–30 min) and max snoozes (1–10 / unlimited). Snoozing skips the mission.
- ✅ Rings with the phone locked and on silent (background audio keep-alive).
- ✅ **Volume lock**: the volume buttons can't turn a ringing alarm down (works locked too).
- ✅ Backup notifications if iOS kills the app (10 notifications, 30 s apart, per alarm).
- ✅ Test buttons in each alarm: "Save & ring in 5 s", "15 s (lock your phone)", "3 minutes (tests the lock-screen card)". Test alarms never count in stats.
- 🧪 **Custom sounds**: "Import sound from Files…" (MP3/M4A/WAV). Used for any alarm; delete in Settings → Your sounds.

## Ringing screen
- ✅ Solid black; time, label, Snooze, Start mission / Turn off.
- ✅ Alarm volume drops while you do a mission and comes back up if you leave the app.

## Lock-screen card (Live Activity)
- ✅ "Next alarm · label · time" while an alarm is set (needs Rise opened at least once in the last 8 hours).
- ✅ Switches to **"Wake up!" + Snooze + Stop** when it rings, if the alarm was set more than about 2 minutes earlier. The buttons open Rise, so the phone has to be unlocked.
- ✅ The "Tap to turn it off" notification only appears when no card is showing.
- On iPhones with a Dynamic Island the card also shows there (not yet tested on one).

## Missions (run in order; all must be done)
| Mission | Status | Settings |
|---|---|---|
| Math | ✅ | count 1–10; Easy / Normal / Hard / Super hard |
| Shake | ✅ | count 5–100; Light / Normal / Hard (screen fills as you shake) |
| Scan a code | ✅ | register any QR or barcode; name the spot |
| Memory tiles | ✅ | rounds 1–10; 3×3 / 4×4 / 5×5 |
| Typing | ✅ | phrases 1–10; Short / Medium / Long (15+ phrases each, never repeated) |
| Tap challenge | ✅ | 20–150 taps in 10 s |
| Photo match | ✅ | reference photo; Easy / Normal / Strict (shows a score when it doesn't match) |
| Say the word | ✅ | 1–10 words (speech recognition, alarm muted while listening) |
| Steps | ❌ removed in 0.6.1 | |
| Squats | ❌ removed in 0.6.1 | |

If a mission can't run (camera or mic permission off, no reference photo), it switches to **hard maths** so you're never stuck.

## Extras (per alarm, "Extras" section): 🧪 not confirmed yet
- **Gentle wake-up:** fades from near-silent to full over 30 s.
- **Backup loud sound:** switches to a full-volume siren if nothing is pressed for 40 s.
- **Wake-up check:** 1/3/5/10/15 min after turning it off, asks "Are you up?". Miss the 100 s window and it rings again, mission included.
- **Talking alarm:** reads the time and/or the label every minute until the mission starts.
- **Emergency escape** (Settings → Missions toggle): an "Emergency" button on missions; type a pledge to skip. The pledge gets longer each use (reset in Settings).

## Stats: 🧪 not confirmed yet
- Home-screen **🔥 streak card** (appears after the first real alarm) opens the stats page: current and best streak, a 14-day chart of time to get up, averages, snoozes, escapes, missed checks, recent mornings, reset.
- A morning "counts" when there was no snooze, no emergency escape and no missed wake-up check.

## Weather (Open-Meteo, free, no account)
- ✅ Header card: place ›, big temperature, condition, high/low, next 12 hours; day blue / night navy.
- ✅ Detail page (tap the place): feels like, air quality gauge (European AQI), high/low/wind/humidity, hourly rain chance.
- ✅ "Use my current location" (iPhone permission prompt) or search by town. Pull to refresh.

## Settings
- 🧪 **About** (0.7.3): icon, version and build, app ID, licence, links to "What's new" (Releases) and the source code, and a button that copies the AltStore source link. The quickest way to check an AltStore update worked.
- 🧪 **Signing** (0.7.1): "at least X days left" from the installed profile, then "Refreshed by AltStore ✓" once AltStore has renewed it. The old 24 h / 3 h re-sign reminders were removed, since they'd fire even after AltStore refreshed. AltStore → My Apps shows the exact days left.
- ✅ Lock-screen card status, last error, "Try starting the card now".
- ✅ Notifications status, phone volume, "Ring a test alarm in 10 seconds", tips.
- 🧪 Your sounds (delete imported sounds); Missions → Emergency escape toggle + reset.

## Look
- ✅ Dark UI with orange accent, solid black top bar, sunrise app icon (also used for notifications).
