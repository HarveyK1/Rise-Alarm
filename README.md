An iPhone alarm clock you have to get up to turn off. Rise rings until you finish a wake-up mission: solve sums, shake the phone, scan a code in another room, and more.

**Current version: 0.7.4**, for iOS 17 and later.

> **Upgrading from 0.7.1 or earlier?** Version 0.7.2 has a new app ID, so AltStore treats it as a new app. Install Rise from the source again, delete the old copy, and set your alarms up once more.

## Install (AltStore)

1. In AltStore, go to **Sources → +** and paste:
   ```
   https://raw.githubusercontent.com/HarveyK1/Rise-Alarm/main/altstore-source.json
   ```
2. Open **Browse → Rise → Install**.
3. New versions appear as updates in **My Apps**.

AltStore keeps Rise signed by refreshing it every 7 days. That's AltStore's normal requirement, and it needs AltServer running on your computer on the same Wi-Fi. Every version is also on the [Releases](https://github.com/HarveyK1/Rise-Alarm/releases) page as `Rise.ipa`.

## Features

- **Wake-up missions:** maths, shake, scan a QR code or barcode, memory tiles, typing, tap challenge, photo match, say the word.
- **Rings properly:** plays on silent and with the phone locked; the volume buttons can't turn it down.
- **Lock-screen card** showing your next alarm, which switches to "Wake up!" with Snooze and Stop.
- **Extras:** gentle wake-up, backup loud siren, wake-up check, talking alarm, emergency escape.
- **Your own alarm sounds** (import from Files) plus 5 built-in ones.
- **Weather** at the top (current location or any town) with a detailed forecast page.
- **Wake-up streaks and stats.**

Full details: [docs/FEATURES.md](docs/FEATURES.md).

## Good to know

- Rise rings by keeping itself running in the background, because iOS 17 doesn't give apps a real alarm API. So open Rise once after restarting your phone, don't swipe it away at night, and avoid Low Power Mode.
- The lock-screen card lasts 8 hours after you last opened Rise, so open it before bed.

## Building from source

Rise is a SwiftPM app built on Windows, with no Mac, using WSL + [xtool](https://github.com/xtool-org/xtool) as the compiler. It produces an **unsigned** `Rise.ipa`, and AltStore signs it when it installs. Toolchain setup is in [docs/SETUP.md](docs/SETUP.md); how the app works inside is in [docs/TECHNICAL-NOTES.md](docs/TECHNICAL-NOTES.md).

1. Bump the version (`CFBundleShortVersionString` and `CFBundleVersion`) in **both** `Rise/Info.plist` and `Rise/RiseWidget-Info.plist`.
2. Build (PowerShell, from the repo folder):
   ```powershell
   wsl -d Ubuntu -u root --cd "$PWD" -- bash -c "tr -d '\r' < Rise/build.sh > /root/build.sh && bash /root/build.sh"
   ```
3. Publish: commit and push the code, then `gh release create v<version> Rise.ipa --title "Rise <version>" --notes-file notes.md`, then `python update_source.py "what changed"` and commit and push `altstore-source.json`.

```
Rise/                       the app (SwiftPM + xtool project)
├── Package.swift           targets: Rise (app), RiseWidget (lock-screen card), RiseShared
├── xtool.yml               bundle id, Info.plist paths, icon, widget extension
├── Info.plist              app keys and permissions (version lives here)
├── RiseWidget-Info.plist   widget keys (version must match the app's)
├── Icon.png, make_icon.py  app icon and the script that draws it
├── build.sh                builds Rise.ipa (runs inside WSL)
└── Sources/                Swift code
altstore-source.json        the AltStore source (generated by update_source.py)
update_source.py            adds the built Rise.ipa to the source (versions and permissions read from the IPA)
docs/                       features, setup, technical notes, history, ideas
```
